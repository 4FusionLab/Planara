## О проекте

**Planara** — будущий аддон для Autodesk Fusion от **4FusionLab**.

Цель проекта — упростить получение плоских развёрток поверхностей обычных твёрдых тел для проектирования, прототипирования и изготовления, без необходимости перестраивать модель как листовой металл.

## Статус

🚧 **Ранняя стадия разработки.** Planara пока недоступна для скачивания. Возможности, поддерживаемая геометрия и сроки выпуска ещё не определены.

Следите за обновлениями в репозитории.

## Немного мифологии мастерской

**Planara** — богиня плоских миров, открывающая скрытую плоскость внутри каждой формы.
