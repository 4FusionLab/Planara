## О проекте

**Planara** — будущий аддон **Fusion 360 для развёртки поверхностей и уплощения граней 3D-моделей** от **4FusionLab**. Проект предназначен для получения плоских 2D-развёрток выбранных поверхностей обычных твёрдых тел.

Цель проекта — упростить получение плоских развёрток поверхностей обычных твёрдых тел для проектирования, прототипирования и изготовления, без необходимости перестраивать модель как листовой металл.

## Статус

🚧 **Ранняя стадия разработки.** Planara пока недоступна для скачивания. Возможности, поддерживаемая геометрия и сроки выпуска ещё не определены.

Следите за обновлениями в репозитории.

**Доступные аддоны Fusion 360 от 4FusionLab:** [Perfora — перфорация и узоры](https://github.com/4FusionLab/Perfora) · [Selectra — выбор похожей геометрии](https://github.com/4FusionLab/Selectra) · [Ejix — извлечение объёмов](https://github.com/4FusionLab/Ejix) · [RuEn — горячие клавиши при русской раскладке](https://github.com/4FusionLab/RuEn)
